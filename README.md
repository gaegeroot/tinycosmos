# Check In

A weekly check-in for groups of friends.

Each week, everyone in the group gets the same prompt. Once people have answered, all the answers are shared with the group, so friends stay involved in each other's lives without needing a constant group chat.

## Status

Early development. So far there is only a static welcome page, with **Sign up** and **See how it works** buttons that don't do anything yet.

## Getting started

Requires Flutter **3.47.9**.

```bash
flutter pub get
flutter run
```

For the full setup, see [DEVELOPMENT.md](DEVELOPMENT.md).

## Platforms

The project includes Android, iOS, web, macOS, Windows and Linux targets. The app ID is `com.gaegeroot.checkin`.
